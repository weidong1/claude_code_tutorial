# 去 AI 味写作（de-AI）

目标：把 AI 生成、读起来「一眼假」的中文技术文章，改写成真人开发者写出来的样子。只改「叙述的人味」，技术事实、命令、代码、链接、图片一个字都不许动。

## 第一步：识别「AI 味」——逐条对照划掉

### 结构 / 连接词套路
- 「首先 / 其次 / 再次 / 最后」「综上所述」「总而言之」「不难发现」「由此可见」「值得注意的是」
- 「不仅…而且…」「既…又…」「一方面…另一方面…」
- 每段开头都是「XX 是 / 在于 / 的本质是」这种定义式
- 每段结尾硬凑一句「金句」收束

### 词汇套路
- 空话套话：赋能、抓手、闭环、心智、范式、沉淀、底层逻辑、顶层设计
- 装腔作势：本质上、从某种意义上说、某种程度上、某种意义上讲
- 万能评价：令人惊艳、值得深思、发人深省

### 标点 / 排版
- 破折号「——」泛滥：一段出现两个以上就要砍，多数拆成两个短句
- 冒号解释成瘾：「A：B，C：D，E：F」连环冒号
- 加粗太多：每段都有关键词加粗，像划重点
- 三条式排比工整到假

### 语气
- 四平八稳、没有立场、谁也不得罪
- 「我的观点是 / 我的感受是 / 我的体感是 / 我的判断是」这种公式化开头
- 每个技巧都要硬配一句「感悟」，像在完成任务
- 感叹号、emoji、营销腔

## 第二步：改成「人写的」——七条原则

1. **有立场，敢下判断**：不好用就说不好用，踩了坑就明说。删掉「见仁见智」「仅供参考」。
2. **有具体，少抽象**：把「效率显著提升」换成「半天把一天半的活干完了」；抽象词（闭环、心智）能删就删，删不掉就落到具体动作。
3. **长短句交错**：一段里别全是整齐的排比；故意在长句后接一个短句，制造节奏。
4. **口语化但不随便**：可以用「其实」「说白了」「这玩意儿」「我试下来」，但别用网络烂梗和表情包腔。
5. **破折号收敛**：一段最多一个「——」，优先拆成两个短句。
6. **观点融进叙述里**：把「我的观点是 X」删掉，直接写 X，让立场从行文里自然带出来。
7. **允许不完整**：真人不会每段都收束得漂漂亮亮；该停就停，留一点口语的毛边。

## 第三步：改写的具体操作

- 先通读，把上面「AI 味」清单里的词和句式全部标出来。
- **逐段重写，而不是逐句替换**——换一个词救不了假，要把整段的节奏和口气换掉。
- 技术事实、命令、代码块、链接、图片引用、占位符，**一字不动**。
- 改完大声读一遍：凡是读到「这里怎么这么像 AI」的句子，拆掉重写。

## 判断标准（改完再读一遍）

- 会不会有真人读者在评论区问「这是 AI 写的吧」？有，就是没改干净。
- 能不能想象出作者这个人的语气和偏好？想象不出来，说明还在端着。
